# Basic Image Processing Using JAVA

## Problem Statement
The need for a flexible image processing tool that allows users to perform multiple enhancements on images led to the development of this project. The application should:
- Load an image from a file
- Apply different image manipulation techniques
- Save the edited image back to a file

## Solution
This project is a Java-based Image Editor developed by me as part of a mini-project for **Scaler School of Technology’s Computer Programming class**. The application provides various image processing features such as rotating, converting to grayscale, blurring, and more, all accessible through a text-based interface.

## Tech Stack
- **Programming Language:** Java
- **Libraries Used:** Java AWT, Java Swing, BufferedImage API

## Brief Overview of Process
1. Load an image using BufferedImage.
2. Apply user-selected transformations such as inversion, rotation, or grayscale conversion.
3. Process the image pixel by pixel.
4. Display the modified image.
5. Save the output image to a file.
